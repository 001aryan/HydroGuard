# HydroGuard

A Cloud-Integrated AIoT System for Water Quality and Level Monitoring


📘 **Overview**

HydroGuard is an AIoT-based smart monitoring system that tracks water quality and levels in real time using IoT sensors, AI analytics, and cloud integration.

🚀 **Features**

Real-time monitoring of pH, turbidity, temperature, dissolved oxygen, and water level

AI-based anomaly detection using ML/DL models

Cloud storage & dashboard (AWS/Azure/GCP)

Edge processing via ESP32 / Raspberry Pi

Automated alerts via SMS, Email, or App


⚙️ **Tech Stack**

Hardware: ESP32, pH, Turbidity, DO, Ultrasonic sensors

Cloud: AWS IoT Core / DynamoDB

AI Models: SVM, Decision Tree, LSTM, CNN

Frontend: Web Dashboard for visualization


📊 **Results**

Accuracy: 97.3% (CNN Model)

Latency: < 300ms

Scalable and energy-efficient monitoring
